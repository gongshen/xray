## Business Description

- **Business Description**: 这是一个代理服务器管理平台，用于管理多台代理服务器（基于 xray/v2ray），监控流量使用情况，管理用户绑定关系，以及配置服务器参数。

- **Business Transactions**:
  1. **服务器管理**: 管理员添加、编辑、删除代理服务器，配置服务器参数
  2. **用户绑定**: 将用户绑定到特定的代理服务器，管理用户的代理访问权限
  3. **流量统计**: 实时收集和展示各服务器、各用户的流量使用情况
  4. **流量重置**: 按月重置服务器流量配额
  5. **配置同步**: 将服务器配置同步到各代理服务器节点
  6. **用户管理**: 管理系统用户、角色、权限

- **Business Dictionary**:
  | 术语 | 含义 |
  |------|------|
  | Server | 代理服务器节点，运行 xray 服务 |
  | Binding | 用户与服务器的绑定关系 |
  | Stat | 流量统计数据（上行/下行） |
  | Quota | 流量配额 |
  | stat程序 | 运行在每个代理服务器上的流量采集程序 |
  | Tag | 流量统计中的用户标识 |

## Component Level Business Descriptions

### gin-vue-admin/server (后端服务)
- **Purpose**: 提供管理平台的后端 API 服务
- **Responsibilities**:
  - 用户认证与授权 (JWT + Casbin)
  - 代理服务器 CRUD 管理
  - 用户-服务器绑定管理
  - 流量数据存储与查询
  - 配置文件生成与下发

### gin-vue-admin/web (前端应用)
- **Purpose**: 提供管理平台的 Web 用户界面
- **Responsibilities**:
  - 管理员操作界面
  - 流量数据可视化
  - 服务器状态监控
  - 用户管理界面

### stat (流量采集程序)
- **Purpose**: 运行在每个代理服务器上，采集并上报流量数据
- **Responsibilities**:
  - 连接本地 xray 服务获取流量统计
  - 接收管理平台的配置更新
  - 重启 xray 服务
