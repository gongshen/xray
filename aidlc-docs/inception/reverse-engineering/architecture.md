# System Architecture

## System Overview

代理服务器管理平台采用前后端分离架构，基于 gin-vue-admin 框架二次开发。系统由三个主要组件构成：Vue 3 前端、Gin 后端、以及部署在各代理服务器上的 stat 流量采集程序。

## Component Descriptions

### gin-vue-admin/server
- **Purpose**: 后端 API 服务，处理所有业务逻辑
- **Responsibilities**: 
  - 用户认证授权
  - 代理服务器管理
  - 流量数据处理
  - 配置管理
- **Dependencies**: MySQL, Redis, xray-core
- **Type**: Application

### gin-vue-admin/web
- **Purpose**: 前端 Web 应用
- **Responsibilities**: 
  - 用户界面展示
  - 数据可视化
  - 用户交互
- **Dependencies**: gin-vue-admin/server API
- **Type**: Application

### stat
- **Purpose**: 代理服务器流量采集程序
- **Responsibilities**: 
  - 采集 xray 流量数据
  - 接收配置更新
  - 重启 xray 服务
- **Dependencies**: xray-core gRPC API
- **Type**: Application (Agent)

## Integration Points

- **External APIs**: 
  - xray gRPC Stats API (流量统计)
  
- **Databases**: 
  - MySQL (主数据库)
  - Redis (JWT 黑名单、缓存)

- **Third-party Services**: 
  - 七牛云/阿里云/腾讯云 OSS (文件上传，可选)

## Infrastructure Components

- **Deployment Model**: 
  - 管理平台: Docker/Docker Compose 或 Kubernetes
  - stat 程序: 直接部署在各代理服务器上

- **Networking**: 
  - 管理平台端口: 8888 (后端), 8080 (前端)
  - stat 程序端口: 56611
